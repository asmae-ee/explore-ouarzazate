# 🏜️ Discover Ouarzazate

A tourism website dedicated to exploring the beauty, history, and cultural heritage of **Ouarzazate, Morocco**, also known as the Hollywood of Africa.

## ✨ Features

- Explore historical kasbahs and traditional architecture.
- Discover beautiful oases and natural landscapes.
- Learn about Ouarzazate's cinema heritage.
- Navigate through an Arabic-language interface.
- Enjoy a visually engaging website design.

## 🛠️ Technologies Used

- HTML5
- CSS3
